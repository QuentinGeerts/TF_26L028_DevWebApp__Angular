# Exercice 02 - Thermostat

Créer un composant features/exercices/exo02-thermostat

Le composant aura une propriété :
- Température (valeur de départ: 19)

--- 

Vous devrez afficher les informations suivantes :

```bash
Température : 19°C
[+] [-] [Confort]
```

Comportement des boutons :

- [+] augmente la température de 1
- [-] diminute la température de 1
- [Confort] remet directement la témpérature à 21

Contrainte: la température doit être un signal
