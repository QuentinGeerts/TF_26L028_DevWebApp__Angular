# Exercice 05 - Liste de produits

- Création d'un modèle Product : 
    - Name 
    - Price 
    - Promo (bool) 
    - stock 
    - description

- Création d'une liste dans le typescript ( signal )

- Affichage de la liste avec la directive NgFor dans la vue HTML

- Si le produit est en promotion afficher un message ( et style pour le prix et la couleur de fond)

- Ajouter deux boutons :  + -  pour modifier le stock du produit

- Si la quantité est à zéro ne pas afficher le produit mais un message produit indisponible (switch)

- Bonus : Ajouter plusieurs input pour l'ajout d'un produit ( two-way-bindig )
