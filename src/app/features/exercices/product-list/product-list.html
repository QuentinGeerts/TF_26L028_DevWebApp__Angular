product-list

  1. Création d'un modèle Product : Name - Price - Promo (bool) - stock - description
  2. Création d'une liste dans le typescript
  3. Affichage de la liste avec la directive NgFor
  4. Si le produit est en promotion afficher un message ( et style pour le prix et la couleur de fond)
  5. Ajouter deux boutons : + - pour modifier le stock
  6. Si la quantité est à zéro ne pas afficher le produit mais un message produit indisponible (switch)
  7. Bonus : Ajouter plusieurs input pour l'ajout d'un produit
