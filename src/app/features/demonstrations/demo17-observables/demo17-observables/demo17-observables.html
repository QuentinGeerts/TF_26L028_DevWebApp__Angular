Observables

Les observables

Un observable (fourni par la librairie RxJS) est un objet qui émet des valeurs au fil du temps.

Il permet de gérer des flux de données asynchrones : requêtes HTTP, événements utilisateur, timers…

Contrairement à une promesse qui ne renvoie qu'une seule valeur, un observable peut émettre plusieurs valeurs successives.

La souscription

Un observable est « paresseux » : il ne s'exécute que lorsqu'on s'y abonne avec la méthode subscribe().

La souscription reçoit trois types de notifications :

  • next : une nouvelle valeur est émise ;
  • error : une erreur s'est produite, le flux s'arrête ;
  • complete : le flux est terminé, plus aucune valeur ne sera émise.

Il est important de se désabonner avec unsubscribe() (au plus tard dans ngOnDestroy) pour éviter les fuites de mémoire.

Démonstration

Compteur

Un observable émet une valeur par seconde tant qu'on est abonné. « Arrêter » se désabonne du flux.

Valeur reçue : {{ counterValue() }}

Flux de produits avec filtre

L'observable émet des produits ; l'opérateur filter ne laisse passer que ceux dont le prix est supérieur à 0.

Exemples

Souscrire à un observable

counterValue = signal<number | null>(null);

startCounter() {
  this.counterSubscription = this.observableService.getCounter().subscribe({
    next: (value) => this.counterValue.set(value),
    complete: () => console.log('Observable terminé'),
  });
}

Se désabonner

stopCounter() {
  this.counterSubscription?.unsubscribe();
}

// À la destruction du composant, on nettoie l'abonnement
ngOnDestroy() {
  this.stopCounter();
}

Les opérateurs (pipe)

Les opérateurs RxJS (filter, map…) transforment le flux avant la souscription.

this.observableService.getShoppingItem()
  .pipe(
    filter(item => item.price > 0)
  )
  .subscribe({
    next: (item) => this.products.update(list => [...list, item]),
  });
