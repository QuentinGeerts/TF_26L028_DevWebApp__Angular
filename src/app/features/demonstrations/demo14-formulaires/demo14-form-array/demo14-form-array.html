Champs dynamiques avec FormArray

Un FormGroup convient quand le nombre de champs est fixe et connu à l'avance. Mais comment gérer une liste de champs dont l'utilisateur décide de la taille — plusieurs numéros de téléphone, plusieurs adresses, plusieurs pouvoirs pour un héros ?

C'est le rôle du FormArray : un tableau de contrôles dans lequel on peut ajouter et supprimer des FormControl à la volée. Sa valeur est un tableau (string[] ici), et comme pour le FormGroup, il n'est valide que si tous ses contrôles le sont.

Côté TypeScript, le FormArray se déclare comme un champ du groupe, ici initialisé avec un premier contrôle vide :

myForm = this.fb.group({
name: ['', []],
power: this.fb.array([this.fb.control('')])
});

Un getter permet d'y accéder facilement (avec le bon typage) depuis le template et les méthodes :

get power() {
return this.myForm.get('power') as FormArray;
}

L'ajout et la suppression manipulent le tableau de contrôles — removeAt(index) supprime le champ à n'importe quelle position, pas seulement le dernier : 

addPower() {
this.power.push(this.fb.control(''));
}

removePower(index: number) {
this.power.removeAt(index);
}

Côté HTML, trois éléments entrent en jeu :

  • formArrayName="power" sur un conteneur délimite la zone du FormArray;
  • un @for parcourt power.controls pour générer un input par contrôle — avec track control (par identité, pas par index : voir la remarque plus bas) ;
  • [formControlName]="$index" relie chaque input à sa position dans le tableau (entre crochets cette fois : l'index est une expression, pas un nom fixe).
<div formArrayName="power">
@for (control of power.controls; track control) {
<input [formControlName]="$index">
<button type="button" (click)="removePower($index)">Supprimer</button>
}
</div>

track : avec track $index, supprimer un champ au milieu donne l'impression que c'est toujours le dernier qui disparaît — Angular identifie les éléments par leur position et recycle mal les nœuds. Avec track control, chaque champ est identifié par son objet FormControl, et la suppression retire visuellement le bon élément.

À la soumission, myForm.value retourne { name: string, power: string[] } — le tableau est déjà construit, prêt à l'emploi.
