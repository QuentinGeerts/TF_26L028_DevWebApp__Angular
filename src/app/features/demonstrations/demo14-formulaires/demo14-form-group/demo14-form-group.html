3. Regrouper plusieurs champs avec FormGroup et FormBuilder

Dès qu'un formulaire contient plusieurs champs, on les regroupe dans un FormGroup : un objet qui rassemble plusieurs FormControl et expose la valeur du formulaire complet sous forme d'objet, ainsi que son état global (le formulaire est valide si tous ses contrôles le sont).

Plutôt que d'instancier chaque FormControl à la main, on utilise le service FormBuilder : une « usine » qui allège la syntaxe — chaque champ se déclare par un simple tableau [valeurInitiale, validateurs].

Prérequis : ReactiveFormsModule (le même que pour FormControl).

Côté TypeScript, on injecte le FormBuilder puis on construit le groupe — chaque clé devient un champ du formulaire :

private fb = inject(FormBuilder);

this.formUser = this.fb.group({
    name: ['', []],
    email: ['', []],
    password: ['', []],
    city: ['', []],
    image: ['', []]
});

Côté HTML, la liaison se fait à deux niveaux :

  • [formGroup] sur la balise < form>< /form> relie le formulaire à l'objet FormGroup;
  • formControlName="cle" sur chaque input le relie au contrôle correspondant du groupe (la clé, sans crochets : c'est un nom, pas un binding).
< form [formGroup]="formUser" (ngSubmit)="addUser()">
    < input type="text" formControlName="name">
    < input type="email" formControlName="email">
    ...
    < button type="submit">Add< /button>
    < /form>

À la soumission, this.formUser.value retourne directement un objet { name, email, password, city, image } — prêt à être envoyé à une API ou ajouté à une liste.
