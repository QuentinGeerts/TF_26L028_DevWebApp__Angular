Form Control

Angular propose deux approches pour lier un champ de saisie à une valeur TypeScript : le two-way binding (simple et rapide) et les formulaires réactifs (plus puissants : validation, suivi d'état, etc.).

1. Two-way binding avec ngModel

L'approche la plus directe : l'input et la propriété TypeScript restent synchronisés dans les deux sens — toute saisie met à jour la propriété, et inversement.

Prérequis : importer FormsModule, puis utiliser la syntaxe [(ngModel)] :

<input type="text" [(ngModel)]="valueTwoWay">

Valeur : {{valueTwoWay}}

2. Formulaire réactif avec FormControl

Ici, le champ est représenté par un objet TypeScript de type FormControl. C'est lui qui détient la valeur, mais aussi l'état du champ : validité, champ modifié ou non (dirty), visité ou non (touched)...

Prérequis : importer ReactiveFormsModule.

Côté TypeScript, on déclare le contrôle (valeur initiale + validateurs éventuels) :

valueFormControl = new FormControl('', []);

Côté HTML, deux liaisons entrent en jeu :

  • [formControl] relie l'input à l'objet FormControl;
  • (ngSubmit) sur la balise <form> déclenche une méthode à la soumission.
<form (ngSubmit)="soumissionForm()">
    <input type="text" placeholder="entrez une valeur" [formControl]="valueFormControl">
    <button type="submit">soumettre</button>
</form>

Valeur du formulaire : {{valeurAffichage()}}
