Parent

On retrouve une autre possibilité pour transmettre du contenu du parent à l'enfant : la directive ng-content.

Il suffit de placer le contenu à transmettre entre les balises du composant enfant.

Et de les afficher dans le composant enfant en utilisant la directive ng-content.

Balise "Enfant" dans le composant "Parent":

< app-demo11-ng-content-enfant>
Voici un texte du parent
< /app-demo11-ng-content-enfant>

Affichage dans le composant "Enfant":

L'utilsation de la directive ng-content permet d'afficher le contenu transmis depuis le parent.

< ng-content>< /ng-content>

Voici un texte du parent
