Démonstration 03 - Property Binding

Les crochets [propriete]="expression" évaluent du TypeScript et le posent sur la propriété de l'élément. Sans crochet, c'est du texte.

Sur une image

Sur un champ de saisie

La propriété value vaut: {{ prenom() }}

Le property binding étant en One-Way, la valeur est récupérée du TS et affichée dans le template. Si nous mettons à jour le champ, la modification ne se fait pas dans le TS.

Attribut class :

[class.ma-classe]="condition" ajoute la classe si l'expression est vraie, la retire si l'expression est fausse.

Attribut style :

[style.propriete.unite]="valeur" ajoute le style avec une valeur provenant du TypeScript.
