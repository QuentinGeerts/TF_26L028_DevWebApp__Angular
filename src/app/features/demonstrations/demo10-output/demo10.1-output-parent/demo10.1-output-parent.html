Communication Enfant / Parent avec le Output

Dans ce cas, l'enfant émet une valeur via le décorateur @Output et le parent la reçoit via un gestionnaire d'événement.

La logique fonctionnelle est implémentée dans le composant parent.

Et le composant enfant va implémenter un "output" qui permet d'émettre des événements vers le parent.

Le output est donc un émetteur d'événements.

Dans cette exemple le parent contient une liste de messages et une méthode pour les ajouter.

On retrouve également deux syntaxes pour déclarer les outputs :

Ancienne syntaxe :

valeurEnfant : string = '';
@Output() emitValue = new EventEmitter<string>()
envoieValeur() {
  this.emitValue.emit(this.valeurEnfant)
}

Nouvelle syntaxe :

valeurEnfant : string = '';
emmeteurSignal = output< string>()
envoieValeur() {
  this.emitValue.emit(this.valeurEnfant)
}

Dans les deux cas l'information sera passée au travers de la balise enfant appelée dans le composant parent.

Ici les parenthèses représentent les événements émis par l'enfant :

< app-demo10-output-enfant
        (emitValue)="addMessage($event)"
        (emmeteurSignal)="addMessage($event)"
        >< /app-demo10-output-enfant>
