Communication Parent / Enfant avec Input

Le parent peut transmetre une information à l'enfant au travers d'un input

Le composant "Parent" contient une information à partager à un composant "Enfant"

Le composant "Enfant" devra configurer un "Input" ce qui permet de lui passer une information lors de l'appel du composant au travers de sa balise

Il est possible de passer des types primitifs ou des objets complexes la syntaxe sera la même dans les deux cas

On retrouve deux syntaxe actuellement

Voici l'ancienne syntaxe qui utilise @Input():

@Input() valeurRecu : string = 'valeur par défaut enfant';

Voici la nouvelle syntaxe qui utilise les signaux input() qui peut être typée input< T>():

message2 = input< string>('valeur par défaut 2')

Dans les deux cas, l'information est passée au travers de la balise du composant enfant dans la balise ouvrante en utilisant les accolades []:

les accolades signifient que la valeur est passée par référence

< app-composant-enfant 
[valeurRecu]="message"
[message2]="message">
< /app-composant-enfant>
