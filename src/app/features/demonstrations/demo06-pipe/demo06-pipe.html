Démonstration 06 - Pipes

Un pipe est une fonction de transformation appliquée à une valeur directement dans le template

via la syntaxe :

{{valeur | nom_pipe : 'params'}}

Il est possible d'importer le pipe à utiliser uniquement ou d'utiliser l'import du CommonModule pour rendre les pipes existants disponibles en un seul import

Demonstration Pipes

Pipe Number

Le pipe number permet de formater un nombre et de récupérer plus ou moins de décimales

Sans Pipe : {{valeur}}

Avec Pipe Number Sans paramètrre: {{valeur | number }}

Avec Pipe Number et paramètre '0.0-2': {{valeur | number : '0.0-2'}}

{{valeur | number : '0.0-2'}}

Avec Pipe et paramètre '0.0-1': {{valeur | number : '0.0-1'}}

{{valeur | number : '0.0-1'}}

{{valeur | currency : 'EUR'}}

Date Pipe

DatePipe permet de formater une date dans toutes sortes de format

date simple sans pipe : {{date}}

date avec pipe date sans paramètres : {{date | date}}

{{date | date}}

date signal avec pipe date sans paramètres :{{dateSignal() | date}}

{{dateSignal() | date}}

Json Pipe

Le pipe json permet de formater un objet JSON dans le template

Ce qui peut être utile pour déboguer ou afficher des données structurées
