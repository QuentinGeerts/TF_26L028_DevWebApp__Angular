Démonstration 06 - Pipes

Un pipe est une fonction de transformation appliquée à une valeur directement dans le template

via la syntaxe :

{{valeur | nom_pipe : 'params'}}

Demonstration Pipes

Ici on utilise une valeur en string pour la passer en majuscule

Pipe Uppercase

Sans Pipe : {{message}}

Avec Pipe : {{message | uppercase}}

Pipe Uppercase avec signal

Il est possible d'utiliser les signaux avec les pipes

Signal sans pipe : {{messageSignal()}}

Signal avec pipe : {{messageSignal() | uppercase}}

Pipe Lowercase

Lowercase pour passer le texte en minuscules

Sans Pipe : {{message}}

Avec Pipe : {{message | lowercase}}

Pipe titleCase

titlecase pour passer la première lettre du mot en majuscule

Sans Pipe : {{message}}

Avec Pipe : {{message | titlecase}}

Pipe Slice

Slice pour récupérer une partie d'une chaîne de caractères

Sans Pipe : {{message}}

Avec Pipe : {{message | slice: 0:10}}

Pipe Number

Le pipe number permet de formater un nombre et de récupérer plus ou moins de décimales

Sans Pipe : {{valeur}}

Sans Pipe : {{valeur | number }}

Sans Pipe : {{valeur | number : '0.0-2'}}

Sans Pipe : {{valeur | number : '0.0-1'}}

Pipe Currency

Currency permet d'afficher une valeur en devise avec le symbole approprié

Sans Pipe : {{valeur}}

Avec Pipe Sans paramètres : {{valeur | currency}}

Avec Pipe EUR : {{valeur | currency : 'EUR'}}

Avec Pipe USD : {{valeur | currency : 'USD'}}

Avec Pipe et code EUR : {{valeur | currency : 'EUR' :'code'}}

Sans Pipes symbol en dur : {{valeur}}€

Date Pipe

DatePipe permet de formater une date dans toutes sortes de format

date simple sans pipe : {{date}}

date avec pipe date sans paramètres : {{date | date}}

date signal avec pipe date sans paramètres :{{dateSignal() | date}}

date avec pipe date et format court : {{date | date : 'short'}}

date avec pipe date et format personnalisé : {{date | date :'dd/MM/yyyy'}}

Json Pipe

Le pipe json permet de formater un objet JSON dans le template

Ce qui peut être utile pour déboguer ou afficher des données structurées

{{informationJson}}

{{informationJson | json}}
