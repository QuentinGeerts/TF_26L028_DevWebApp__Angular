Router

Pour la navigation nous avons utilisé le "routerLink" qui permet d'éviter le comportement par défaut de la balise

< a href="">< /a>

Dans certains cas il sera nécéssaire de déclencher la redirection lors d'un événement ou après celui-ci

Nous retrouvons pour cela le Router qui sera injecté comme pour un service et qui nous donne accès à plusieurs methodes

navigate(['/chemin', param]) : navigation par segments de route (tableau), supporte la navigation relative.

navigateByUrl('/chemin/valeur') : navigation par URL complète (string), toujours absolue.

Le router pourra être utilisé dans une methode pour permettre la redirection à un moment donné , comme après la soumission d'un formulaire

Injection du router dans un composant

router = inject(Router)

Utilisation du router dans un composant

navigateToPage(id:number) {
            this.router.navigate(['/details',id])
            }

ActivatedRoute

Il est possible de passer des informations par la route , comme un id vu ci-dessus.

Par exemple sur une page liste on est redirigé vers une page détail

Il sera donc possible de récupérer cette informations dans le composant sur lequel la redirection à lieu

Pour cela il faudra utiliser ActivatedRoute qui nous permet de récupérer la route à un moment donné , comme au chargement du composant

Il suffira d'utiliser une capture de la route pour récupérer un paramètres de cette route .

Le paramètre sera défini dans le fichier app.routes.ts avec la syntaxe : :nom_du_paramètre

Comme : update-article/:id

ActivatedRoute devra être injecté dans notre composant pour pouvoir être utilsé.

activatedRoute = inject(ActivatedRoute)

Il sera possible à partir du moment ou ce paramètre est défini de récupérer l'information dans le composant en utilisant ActivatedRoute

const id = +this.activatedRoute.snapshot.params['id']

Ce qui permet de charger un élément spécifique en fonction de paramètre passé : produit 1 ou produit 2 ...


      ngOnInit(){
    const id = +this.activatedRoute.snapshot.params['id']
    this.article = this.articleService.getArticleById(id)
  }

Le symbole + ici permet une conversion en Number du paramètre , la methode Number() fonctionne également
