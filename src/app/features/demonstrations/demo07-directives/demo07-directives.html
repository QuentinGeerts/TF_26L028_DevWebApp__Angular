Demo Directives

Les directives Permettent de gérer le rendu de notre page html grace à des conditions comme

  • IF
  • For
  • Switch

Valeur pour gérer l'affichage d'un élément on utilise un booléen :

est connecter : {{isLogged()}}

Utilisation de plusieurs If

@if(!isLogged()){

Bonjour connectez-vous.

Vous devez être connectez pour accéder au site

} @if(isLogged()){

Bonjour vous êtes connectez.

Bienvenue sur le site

}

Utilisation de if - else

@if(isLogged()){

Bonjour vous êtes connectez.

Bienvenue sur le site

} @else{

Bonjour connectez-vous.

Vous devez être connectez pour accéder au site

}

For

La directive FOR Permet de parcourir une collection et de définir un affichage commun pour chacun des éléments de la liste

parcourir une collection simple

    @for (p of products; track $index) {

  • {{p.name}}

    {{p.price}}

    {{p.stock}}

    {{$index}}

    • }

For avec un signal

Même fonctionnement que sans signal , ne pas oublier les parenthèze.

@for (p of productsSignal(); track p.id) {

  • {{p.name}}

    {{p.price}}

    {{p.stock}}

    • }
